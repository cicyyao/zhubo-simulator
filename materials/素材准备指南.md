# 素材准备指南

要让模拟器效果逼真，需要准备以下素材。素材质量决定最终效果。

---

## 第一步：提取聊天记录

你有微信聊天截图，需要把文字提取出来。

### 方式一：手动整理（推荐）
直接根据截图，按以下格式整理成文本：

```
她：在吗？
我：在啊咋了
她：哈哈哈哈没事
我：？
她：就是想你了呗～
我：滚蛋
她：哼！
```

### 方式二：截图给我
把截图的文件路径给我，我可以用视觉能力帮你提取文字。注意：
- 截图要清晰
- 尽量包含对话上下文
- 按时间顺序命名：`chat_01.png`, `chat_02.png`...

---

## 第二步：人物信息整理

请尽可能详细地填写以下信息：

### 基本信息
```json
{
  "姓名/昵称": "",
  "性别": "",
  "年龄": "",
  "职业": "",
  "城市": "",
  "你们怎么认识的": "",
  "关系持续时间": ""
}
```

### 性格特征（多选）
- [ ] 外向开朗
- [ ] 内向安静
- [ ] 毒舌/爱怼人
- [ ] 温柔体贴
- [ ] 爱撒娇
- [ ] 高冷/话少
- [ ] 戏精/夸张
- [ ] 理性/冷静
- [ ] 感性/情绪化
- [ ] 其他：

### 语气特征

| 特征 | 描述 |
|------|------|
| 口头禅/高频词 | 如"绝了"、"笑死"、"好吧"、"真的假的" |
| 常用表情/emoji | 如😂🤣😅😏🙄💅 |
| 句子长度 | 长段文字 / 短句 / 一句话拆成好几条 |
| 标点习惯 | 喜欢用"～"、"。。。"、"！！！" |
| 打字风格 | 普通话 / 方言 / 中英混杂 |
| 称呼你的方式 | 全名 / 昵称 / "宝" / "喂" |
| 回复速度 | 秒回 / 轮回 / 看心情 |
| 冷场时 | 发表情包 / 转移话题 / 直接消失 |

### 关系状态
```
我们目前的关系：
- 已经决裂
- 决裂原因：_______
- 她现在对我的态度：_______
- 我对她的真实想法：_______
- 对话中我想扮演的角色：_______
```

---

## 第三步：整理示例对话

从聊天记录中挑出**最有代表性**的10-20条对话片段，覆盖不同场景：

- [ ] 日常闲聊（1-2段）
- [ ] 她吐槽/抱怨（1-2段）
- [ ] 她生气/不爽（1-2段）
- [ ] 她撒娇/示好（1-2段）
- [ ] 她阴阳怪气（1-2段）
- [ ] 她分享生活（1-2段）
- [ ] 她敷衍/不想聊（1-2段）

每段3-8条消息即可。

---

## 素材到位后

把整理好的素材发给我，我会：
1. 根据素材生成精确的 system prompt
2. 配置到模拟器中
3. 让你测试效果
4. 根据你的反馈调整 prompt
